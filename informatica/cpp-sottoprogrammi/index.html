Tappa 1 di 8

Variabili e tipi

Il tipo indica quale genere di dato contiene una variabile. Il nome serve per ritrovarla nel programma.

Come si dichiara una variabile?

1float2lato = 3.0f;
1 Tipo

float indica un numero decimale.

2 Nome

lato è il nome scelto per la variabile.

Una sola dichiarazione nello stesso ambito: non puoi scrivere due volte float lato; nello stesso blocco. Puoi invece cambiarne il valore con lato = 5.0f;.

I tipi principali

Tutti questi tipi possono essere usati per variabili, parametri e, quando appropriato, valori di ritorno.

intNumero interoint eta = 16;
floatNumero decimalefloat lato = 3.5f;
doubleDecimale con più precisionedouble prezzo = 12.75;
boolVero o falsobool acceso = true;
charUn caratterechar iniziale = 'A';
stringTestostring nome = "Luca";
string richiede #include <string> e, negli esempi, using namespace std; oppure il nome completo std::string. Le stringhe usano doppi apici; i char apici singoli.

Dichiarazioni e assegnazioni

La virgola consente di dichiarare più variabili dello stesso tipo. Per iniziare è spesso più leggibile scriverne una per riga.

Tappa 2 di 8

Le 4 parti di una funzione

Una funzione è un blocco di codice con un nome: quando la chiami, esegue un compito.

Impara a riconoscerle

1float2perimetro3(float lato)4{ ... }
1 Tipo restituito

Che tipo di valore arriva all'esterno: qui float.

2 Nome

Serve a chiamare la funzione: perimetro.

3 Parametri formali

Sono gli ingressi, indicati come tipo nome, separati da virgole.

4 Corpo

È il codice tra { e }; se necessario usa return.

Esempio: perimetro di un triangolo equilatero

Chiamata: perimetro(4.0f)→lato = 4→return 4 * 3→12
return restituisce un valore alla parte di programma che ha chiamato la funzione. Non lo stampa automaticamente.

Posso usare altri tipi?

Sì. Il tipo scritto prima del nome dice quale valore restituirà la funzione.

Nota: string è un tipo della libreria standard; void è utilizzato per funzioni che non restituiscono un valore.

Tappa 3 di 8

Parametri formali e argomenti

La funzione definisce quali dati ricevere. La chiamata fornisce i valori effettivi.

Due nomi diversi per due ruoli

Nella definizione
float perimetro(float lato)

lato è il parametro formale.

Nella chiamata
perimetro(5.0f)

5.0f è l'argomento (o parametro attuale).

Argomento 5.0f→Parametro lato riceve 5→Risultato 15

Nel normale passaggio per valore, una copia del valore dell'argomento viene assegnata al parametro: modificare il parametro non modifica la variabile originale.

Da zero a più parametri

Regola: nella definizione ogni parametro richiede il suo tipo: int somma(int a, int b) è corretto; int somma(int a, b) non lo è.

Dove scrivo la funzione?

Puoi definirla prima di main, oppure scrivere il prototipo prima di main e la definizione dopo.

Prototipo: termina con ; e non contiene il corpo. Definizione: contiene { ... }.

Tappa 4 di 8

Funzione o «procedura»?

Nella terminologia scolastica una funzione restituisce un valore, mentre una procedura esegue azioni. In C++ la «procedura» si scrive come funzione void.

Restituisce un valore

Funzione float

Puoi usare il risultato in una variabile o in un'espressione.

Non restituisce valori

Funzione void

Stampa direttamente il risultato. Non può essere usata come se producesse un numero.

Qual è la differenza vera?

Funzione con risultatoFunzione void
Tipofloat, int, ...void
Risultato con returnRestituisce il valoreNon restituisce un valore
Può usare cout?SìSì
Può avere parametri?Sì, anche zeroSì, anche zero
Chiamata tipicafloat p = perimetro(3);stampaPerimetro(3);
Due precisazioni importanti. Una funzione void può contenere return; senza valore, per interrompere l'esecuzione: non è obbligatorio. E «una funzione ha sempre un solo output» è solo una semplificazione iniziale: in C++ esistono anche i riferimenti e altri modi per produrre più risultati.

Domande frequenti

Una funzione float può stampare con cout?
Sì. Il tipo di ritorno dice soltanto quale valore viene restituito con return. Stampare ed effettuare un return sono azioni diverse.
Una funzione void può calcolare qualcosa?
Sì. Può usare variabili locali e fare calcoli, ma non restituisce direttamente il risultato come valore. Può, per esempio, visualizzarlo con cout.
Posso scrivere float x = stampaPerimetro(3);?
No, se stampaPerimetro è void: la chiamata non produce un valore assegnabile a x.

Tappa 6 di 8

Ambito delle variabili ed errori comuni

Per usare bene i sottoprogrammi devi sapere dove esistono le variabili e cosa aspettarsi da return.

Una variabile «vive» nel proprio ambito

Le due variabili chiamate risultato non sono la stessa variabile: una appartiene a quadrato, l'altra a main.

Errore: non puoi usare da main una variabile locale dichiarata dentro quadrato. Devi passare i dati con i parametri e ottenere il risultato con return.

Quattro errori da evitare

1. Dimenticare il tipo di un parametro

Non scrivere int somma(int a, b). Scrivi int somma(int a, int b).

2. Restituire un numero da una funzione void

return 5; non è valido in una funzione void. Puoi scrivere return; oppure ometterlo.

3. Confondere stampare e restituire

cout << area; visualizza un valore. return area; lo rimanda al chiamante. Non sono la stessa cosa.

4. Dimenticare il punto e virgola nel prototipo

Prototipo: int triplo(int n); (con ;). Definizione: int triplo(int n) { return n * 3; } (senza ; dopo la firma).

Promemoria: controlla queste 5 cose

  1. Ho scritto il tipo prima del nome della funzione?
  2. Ogni parametro formale ha tipo e nome?
  3. Le istruzioni sono dentro le graffe?
  4. Se la funzione deve restituire un risultato, uso return valore;?
  5. La funzione è definita o dichiarata prima della chiamata?
